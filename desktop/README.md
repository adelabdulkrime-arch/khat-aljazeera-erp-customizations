# تطبيق سطح المكتب — خط الجزيرة

غلاف [Electron](https://www.electronjs.org/) يفتح النظام في نافذته الخاصة: أيقونة على سطح المكتب وقائمة ابدأ، بلا شريط عنوان متصفح ولا تبويبات.

## ما هو، وما ليس هو

هذا **واجهة** للنظام، وليس النظام نفسه. النظام (ERPNext وقاعدة بياناته) يعمل على السيرفر — جهاز بالورشة أو خادم سحابي — والتطبيق يتصل به.

يعني: **لا بد من سيرفر يعمل.** التطبيق وحده لا يُنشئ نظاماً. راجع [`../LOCAL_DEPLOY.md`](../LOCAL_DEPLOY.md) للتشغيل داخل الورشة أو [`../ORACLE_DEPLOY.md`](../ORACLE_DEPLOY.md) للسحابي.

## بناء `setup.exe`

**كليك يمين على [`build-installer.bat`](build-installer.bat) ← Run as administrator.**

ينتج `release\setup.exe` (~80MB).

**لماذا صلاحية مدير؟** `electron-builder` يفك ضغط أدوات توقيع تحتوي ارتباطات رمزية (symlinks) خاصة بـmacOS، وويندوز يمنع إنشاءها بلا صلاحية مدير أو «وضع المطوّر». السكربت يفعّل وضع المطوّر مرة واحدة، فلا تحتاج صلاحية مدير في المرات التالية.

**لماذا `.bat` وليس `.ps1` مباشرة؟** سياسة التنفيذ الافتراضية (`RemoteSigned`) تمنع سكربتات `.ps1` غير الموقّعة — **وتمنعها بصمت**: تعود الشاشة للسطر التالي بلا أي رسالة، فيبدو أن شيئاً لم يحدث. ملف `.bat` يستدعي السكربت مع تجاوز السياسة لتلك الجلسة فقط، دون تغيير أي إعداد أمني بالجهاز.

**`nsis.warningsAsErrors: false` في [package.json](package.json) — لا تحذفه.** NSIS يرفض اسم `setup.exe` تحديداً (تحذير 9000): ويندوز يحمّل «طبقات توافق» لأي ملف اسمه `setup*`، و`electron-builder` يعامل هذا التحذير كخطأ قاتل فيفشل البناء في خطوته الأخيرة. أبقينا الاسم لأنه المطلوب تسليمه، والسلوك غير ضار لمنصّب يطلب صلاحية مدير أصلاً — فسمحنا بالتحذير صراحةً.

## التشغيل أثناء التطوير

```powershell
npm start
```

> إن ظهر خطأ غامض عن `app` غير معرّف، فالسبب متغيّر البيئة `ELECTRON_RUN_AS_NODE` (يضبطه VS Code)، وهو يجعل Electron يعمل كـNode عادي بلا واجهة. أزله: `Remove-Item Env:ELECTRON_RUN_AS_NODE`

## عنوان السيرفر

الافتراضي `https://khat.onemedia24.xyz` ([src/config.js](src/config.js)).

يغيّره المستخدم من داخل التطبيق: **ملف ← إعدادات الاتصال…** — ويُحفظ في ملف إعدادات بمجلد بيانات المستخدم، فلا يحتاج إعادة بناء عند تغيير الدومين أو الانتقال لسيرفر محلي.

أمثلة صالحة:
- `https://khat.onemedia24.xyz` — سيرفر سحابي
- `http://192.168.1.50` — جهاز بالورشة على الشبكة المحلية

## ملاحظات تقنية

- **جلسة محفوظة:** تسجيل الدخول يبقى بين التشغيلات، فلا يُطلب في كل مرة.
- **حصر التنقّل:** التطبيق لا يبحر خارج عنوان السيرفر. الروابط الخارجية (واتساب مثلاً) تُفتح بالمتصفح الافتراضي.
- **مثيل واحد:** فتح التطبيق مرة ثانية يُظهر النافذة المفتوحة بدل نافذة جديدة.
- **غير موقّع رقمياً:** ويندوز قد يعرض تحذير SmartScreen عند أول تثبيت (**More info ← Run anyway**). إزالته تحتاج شهادة توقيع مدفوعة (~200-400$ سنوياً).
