# فحص صفحة الدخول قبل النشر

صفحة `/login` تُبنى فوق تنسيقات Frappe نفسه، وهي تخدم حزمتَي CSS (عربية وإنجليزية) بقيم معكوسة، وأربعة أقسام يبدّل بينها جافاسكربت. تعديل يبدو سليماً في لقطة واحدة ينكسر في لغة أخرى أو مقاس آخر أو قسم آخر. هذه الأدوات تفحص ذلك كلّه قبل أن يصل أي شيء للخادم.

## الملفات

| الملف | الدور |
|---|---|
| `serve.js` | يقدّم `login.css` و`login_lang.js` وصورة الشعار من المستودع على `127.0.0.1:8765` |
| `checker.js` | يعرّف `window.__kajCheck()`؛ يعيد `{fails: [], info: {}}` |
| `check-strings.js` | تغطية ترجمة رسائل الدخول (يُشغَّل بـnode) |

## الاستخدام

1. `node tools/login-check/serve.js`
2. افتح `/login` على الموقع الحيّ في المتصفح، ثم في الكونسول:

```js
const get = u => fetch('http://127.0.0.1:8765' + u).then(r => r.text());
const [css, chk] = await Promise.all([get('/login.css'), get('/checker.js')]);
document.querySelectorAll('#kaj-login-css').forEach(n => n.remove());   // التنسيق المنشور (‎#kaj-login-vars يبقى: فيه رابط الشعار)
const s = document.createElement('style'); s.textContent = css; document.head.append(s);
eval(chk);
__kajCheck();     // fails فارغة = سليم
```

## ما يُفحص

| المعرّف | العيب |
|---|---|
| `OVERFLOW-X` | تمرير أفقي |
| `FITS` | المحتوى أطول من النافذة (من 480px ارتفاعاً فما فوق) |
| `TOUCH` | حقل أو زر أقصر من 44px |
| `INPUT-FONT` | خط الحقل أقل من 16px (يُكبّر iOS الصفحة عند التركيز) |
| `ICON-OVERLAP` / `ICON-SIDE` / `ICON-VCENTER` | أيقونة فوق النص، أو في الجهة الخطأ، أو منحرفة رأسياً |
| `TEXT-CLIP` | نص مقتطع |
| `CONTRAST` | تباين دون WCAG AA، مع احتساب الشفافية |
| `ALIGN` / `ALIGN-H4` | التسمية أو العنوان لا يبدآن من حافة الحقل |
| `PANEL` | الشعار الكبير غائب من 1024px فما فوق، أو ظاهر تحتها |
| `ART-OUT` / `ART-SMALL` | الشعار خارج النافذة، أو أصغر من 240px |
| `PANEL-OVERLAP` / `SIDES` | البطاقة تتقاطع مع الشعار، أو أحدهما في غير جهته |
| `SYMMETRY` | مركزا الشعار والبطاقة ليسا على بُعد واحد من منتصف الشاشة |
| `GAP-TIGHT` / `GAP-WIDE` | المسافة بين الشعار والبطاقة دون 40px أو فوق 260px |
| `ART-DOMINANT` | الشعار أعرض من 1.25× عرض البطاقة |
| `CARD-OUT` / `CARD-CLIPPED` | البطاقة خارج النافذة أفقياً، أو مقصوصة من الأعلى |
| `FIXED-ON-CARD` / `FIXED-ON-ART` | عنصر ثابت (مبدّل اللغة، «ثبّت التطبيق») يركب البطاقة أو الشعار |
| `FIXED-OVERLAP` / `FIXED-ON-FIXED` / `FIXED-OUT` | عنصر ثابت يغطّي حقلاً أو زراً، أو يركب عنصراً ثابتاً آخر، أو يخرج عن النافذة |

`check-strings.js` يتحقق بمعزل عن المتصفح أن كل رسالة يبنيها جافاسكربت الدخول في الإطار لها ترجمة عربية.

لمحاكاة «ثبّت التطبيق» (يظهر فقط حين يعرض المتصفح التثبيت) أضف عنصراً بمعرّف `kaj-install-fab` وبتنسيق `pwa.js` نفسه قبل تشغيل الفاحص.

## المصفوفة التي يجب أن تنجح قبل أي نشر

اللغتان (`preferred_language=ar|en`) × الوضعان (فاتح/داكن) × الأقسام الثلاثة (`#login`، `#forgot`، `#login-with-email-link`) × المقاسات:

`2560×1300` · `1920×950` · `1536×730` · `1440×680` · `1366×650` · `1280×600` · `1260×590` · `1093×510` · `1024×768` · `1023×700` · `768×1024` · `390×844` · `360×640` · `320×568`

المقاسات بالبكسل المنطقي (CSS)، لا الفيزيائي: شاشة 1920×1080 بتكبير 150% نافذتها نحو `1260×590`، ولابتوب 1366×768 بتكبير 125% نحو `1093×510`. الفحص على نافذة واسعة وحدها يُخفي كل عيوب الارتفاع.

لتجربة مقاس بعينه دون تغيير حجم النافذة، حمّل الصفحة داخل `<iframe>` بالعرض والارتفاع المطلوبين وشغّل الفاحص داخل نافذته — استعلامات الوسائط تُقاس على نافذة الإطار.

## حين يتغيّر الإطار

إن حدّث Frappe صفحة الدخول فشغّل الفاحص على الإطار الخام (بلا تنسيقنا) أولاً: يجب أن **يفشل** (حقول 28px، تباين 4.17). فاحصٌ لا يفشل على الإطار الخام لم يعد يرى شيئاً.
