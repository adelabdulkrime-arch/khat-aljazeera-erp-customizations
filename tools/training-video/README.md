# الفيديو التعليمي

يُنتَج الفيديو من النظام نفسه: متصفح يُقاد آلياً ينفّذ الجولة على نسخة الاختبار
ويُسجَّل، ثم يُركَّب عليه تعليق صوتي عربي وشريط نصّ سفلي. تغيّرت شاشة في النظام؟
يُعاد التسجيل بأمر واحد بدل تصوير يدوي جديد.

## ما فيه

جزآن، وكلٌّ منهما يخرج **جولةً كاملة** في ملف واحد و**مقاطع مستقلة**، مقطع لكل
عملية (دقيقة تقريباً، ببطاقة عنوان ورقم): الموظف يفتح مقطع ما يحتاجه، والمقطع
يُرسَل وحده، وتغيّر شاشةٍ يعيد تسجيل جزئها لا الدليل كله.

- **الجزء الأول** (`narration.js`، 15 مقطعاً): من أول دخول إلى أول فاتورة.
- **الجزء الثاني** (`narration2.js`، 13 مقطعاً): المبيعات والمشتريات والمخزون
  والمحاسبة والإعدادات العامة. يبدأ من بيانات الأول: يُسجَّل بعده على النسخة
  نفسها، بـ`KAJ_PART=2`.

الجزء الأول:

22 مشهداً، نحو تسع دقائق: الدخول ← الرئيسية ← إعدادات الورشة ← فني ← خدمة ← قطعة
← عميل ← مركبة ← بطاقة عمل ← اعتماد ← فاتورة ← سند قبض ← طباعة ← لوحة الورشة وملف
العميل ← رصيد المخزون ← إضافة مستخدم.

| الملف | دوره |
|---|---|
| `narration.js`، `narration2.js` | نصّ كل مشهد في الجزأين: ما يُقال (جملة، أو عدة جمل توزَّع على مدّة المشهد) وما يُكتب أسفل الشاشة. **تعديل الكلام من هنا.** |
| `tts.js` | يولّد التعليق الصوتي (ملف لكل جملة) ويقيس مدّته؛ لا يعيد إلا ما تغيّر نصّه |
| `record.js` | ينفّذ الجولة ويسجّلها؛ كل مشهد يمتدّ حتى ينتهي تعليقه |
| `sync.js` | مؤشّر المزامنة: لون لكل مشهد في زاوية الصفحة، يقرأ منه `build.js` بداية المشهد |
| `build.js` | يركّب: التسجيل + شريط النصّ + الصوت ← MP4 |

## التشغيل

الأدوات (مرة واحدة، في أي مجلد عمل):

```bash
npm install playwright ffmpeg-static msedge-tts && npx playwright install chromium
```

نسخة الاختبار يجب أن تكون **نظيفة** (مستعادة من نظام سُلِّم فارغاً): الجولة تُنشئ
فنياً وأصنافاً وعميلاً بأسماء ثابتة، وتكرارها على البيانات نفسها يصطدم بها.
ثم، والمعاينة المحلية تعمل (`tools/desk-check`):

```bash
export NODE_PATH=<مجلد العمل>/node_modules
node tts.js    <out>               # الصوت
node record.js <out>               # التسجيل (نحو 10 دقائق)
node build.js  <out> <الفيديو.mp4> --clips=<مجلد المقاطع>   # الجولة الكاملة + المقاطع

# الجزء الثاني، بعد الأول وعلى بياناته (مجلد عمل آخر):
export KAJ_PART=2
node tts.js <out2> && node record.js <out2> && node build.js <out2> <الفيديو2.mp4> --clips=<مجلد المقاطع>
```

المشاهد المتتالية التي تحمل `clip` نفسه في ملف النصّ مقطع واحد؛ وما لا `clip` له
(بطاقات العناوين) يبقى في الجولة الكاملة وحدها. ترقيم المقاطع متصل بين الجزأين.

`record.js --dry` يجري الجولة بلا انتظار التعليق، لتجربة الخطوات بسرعة؛ ومعه
`KAJ_SUFFIX=" ت1"` يميّز أسماء كل تجربة فلا تتصادم. لقطة آخر كل مشهد في
`<out>/shots`، ولقطة `FAILED-…` حيث توقّف.

## ملاحظات

- التسجيل على نسخة الاختبار لا الموقع الفعلي: الجولة تُدخل بيانات.
- قبل التسجيل جلسة تمهيد غير مسجَّلة تدخل النظام وتخرج بالملف الشخصي نفسه
  (`<out>/profile`): الفيديو يصوّر دخول متصفحٍ سبق أن فتح النظام — الحال المعتادة —
  لا أول تحميل على الإطلاق.
- الصفحة تُسجَّل 1280×660، والشريط السفلي يضيفه `build.js`. كان النصّ يُرسم فوق
  الصفحة فيغطّي زرّ «حفظ» في الحوارات.
- ساعة التسجيل ليست ساعة الحائط: جولة طولها 700 ثانية خرج ملفّها 727، فكان
  التعليق يسبق الصورة في آخر الفيديو بعشرين ثانية. لذلك يلوّن `record.js` مربّعاً
  صغيراً أسفل يسار الصفحة بلون خاص بكل مشهد، ويقرأ `build.js` بداية كل مشهد من
  الفيديو نفسه (سطر `SYNC` في ناتجه)، ثم يغطّي المربّع بالشريط.
- `record.js` يجمع كل نصّ إنجليزي ظهر على الشاشة أثناء الجولة (رسالة عابرة، وصف
  حقل في حوار) في `<out>/english.json` ويطبعه بسطور `EN`. ما كان منه جملةً لا
  رمزَ صنف فمكانه `glossary.py`، ثم يُعاد التسجيل. (سطور «results found» من قارئ
  الشاشة، لا تُرى.)
- غيّرت جملة في `narration.js`؟ `tts.js` ثم `build.js` يكفيان ما دام المشهد المسجَّل
  يتّسع لها؛ وإلا قال `build.js` أيّ مشهد أقصر من تعليقه، فيُعاد التسجيل.
- بعد التركيب: استخرج إطاراً من وسط مشهدين أو ثلاثة في آخر الفيديو وتأكد أن
  النصّ السفلي يطابق الشاشة.
- الحقول تُملأ بفأرة ولوحة مفاتيح حقيقيتين. حيث لم تثبت القيمة (خلية جدول عنيدة)
  تُثبَّت من خلف الواجهة ويُكتب `FALLBACK` في السجل، فلا يتوقف التسجيل.
- الصوت من خدمة القراءة الصوتية في Microsoft Edge (`ar-OM-AbdullahNeural`). ما
  يُرسَل إليها نصّ `narration.js` وحده. الخدمة تحدّ الطلبات المتتابعة؛ `tts.js`
  ينتظر ويعيد.
